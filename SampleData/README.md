# Synthetic demonstration data

These seven CSV files are invented examples for trying the dashboard. All product, request, manufacturer, factory and BasePart identifiers are labelled DEMO. They are not real Click Spares activity.

Load them through **Data imports**, or copy just the seven CSV files to the server-local `Data/Imports` folder. They are not included in published builds and do not load automatically.

To regenerate the same examples from source, run `node Scripts/Generate-Sample-Data.mjs`.
